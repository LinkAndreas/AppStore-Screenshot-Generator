Редактор обрабатывает всё локально в твоём браузере:

Сохранение твоего проекта в локальном хранилище строго необходимо для работы редактора, которым ты пользуешься (§ 25 абз. 2 п. 2 TDDDG). 5. MCP-сервер для ИИ-агентов

Storyframe предлагает сервер на основе Model Context Protocol (MCP) по адресу screenshots.linkandreas.de/mcp, с помощью которого ИИ-агенты, например Claude или Cursor, могут создавать скриншоты. Если ты подключаешь к нему ИИ-агента, наш сервер обрабатывает запросы, которые отправляет агент:

  • Содержимое для рендеринга: заголовки и описания, цвета, шрифты, макеты, языковые настройки (локали) и скриншоты приложения, которые агент отправляет в виде данных изображения, загрузки или веб-адреса (URL).
  • Загрузки и результаты: загруженные изображения и готовые скриншоты хранятся только в памяти сервера, не записываются на диск и удаляются не позднее чем через один час (раньше, если память заполнена). Готовые файлы может скачать любой, у кого есть ссылка для скачивания; ссылки содержат случайный код, который невозможно угадать.
  • Изображения по веб-адресам: если агент передаёт URL изображения, наш сервер скачивает его по этому адресу. Сайт по этому адресу видит IP-адрес нашего сервера, а не твой.
  • Шрифты для других систем письма: если текст содержит символы, которые не поддерживаются встроенными шрифтами (например, японские, китайские или арабские), наш сервер запрашивает подходящий шрифт Noto у Google Fonts (Google Ireland Limited, Gordon House, Barrow Street, Dublin 4, Ирландия). Запрос содержит символы, использованные в тексте этого экрана, отсортированные и без повторов, и исходит от нашего сервера, а не от твоего устройства.
  • Защита от злоупотреблений: чтобы ограничить число запросов от одного клиента, сервер в течение одной минуты подсчитывает в памяти запросы с каждого IP-адреса.

У MCP-сервера нет аккаунтов, и он не требует ключей доступа. Мы обрабатываем эти данные только для того, чтобы создать запрошенные тобой скриншоты (ст. 6(1)(b) GDPR), и для защиты сервиса от злоупотреблений (ст. 6(1)(f) GDPR). ИИ-агент, которым ты пользуешься, и его поставщик обрабатывают твои данные на собственных условиях и по собственным политикам конфиденциальности, за которые они несут ответственность. Если открыть адрес MCP в веб-браузере, тебя перенаправит на страницу проекта на GitHub (GitHub, Inc., США).

Если же ты запускаешь MCP-сервер на своём компьютере, он создаёт скриншоты локально, и мы не получаем никаких данных. В этом случае с твоего компьютера в Google Fonts отправляется только описанный выше запрос шрифтов для других систем письма.
