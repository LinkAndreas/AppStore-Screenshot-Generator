3. Hosting and delivery of the website

The website runs on a virtual server that we rent from Hostinger (Hostinger International Ltd., 61 Lordou Vironos Street, 6023 Larnaca, Cyprus); the server is located in Frankfurt, Germany. It is delivered through the network of Cloudflare (Cloudflare, Inc., 101 Townsend St., San Francisco, CA 94107, USA): every request to screenshots.linkandreas.de passes through Cloudflare, which provides the encrypted HTTPS connection, forwards the request to our server through a secure tunnel and protects it against attacks and overload.

When you open the website, your browser necessarily transmits technical information, such as your IP address, the date and time of the request, the page or file requested, the referring page and your browser type and version. This information is processed by Cloudflare and our server only to deliver the website and to keep it secure and stable (Art. 6(1)(f) GDPR; our legitimate interest is a secure, working website). The web server on our virtual server does not write access logs. Cloudflare processes connection data on our behalf and may also ask your browser to report failed connections to it (Network Error Logging).

Cloudflare’s Email Obfuscation is active for the linkandreas.de domain: to protect email addresses from spam bots, Cloudflare rewrites the email links on our pages as they are delivered, and a small Cloudflare script, served from the same address as the page, decodes them again in your browser. This processes no personal data beyond the connection data described above.

4. The editor in your browser

The editor processes everything locally in your browser:

  • Screenshots: The images you add are opened directly in your browser and are not uploaded. They are kept only in your browser’s memory and are gone when you reload or close the page.
  • Your project: Headlines and descriptions, styles, layouts, the languages and devices you work on, your light or dark theme and whether you have seen the tutorial and the latest “What’s New” are saved in your browser’s local storage (localStorage), so that your work is still there the next time you open Storyframe.
  • Export: The finished screenshots and the ZIP file are created in your browser and saved directly to your device.
  • Language: The editor reads your browser’s language setting to show its interface in your language; this is not stored or transmitted.

None of this is transmitted to us or to third parties, and we cannot access it. Saving your project in local storage is strictly necessary to provide the editor you use (§ 25(2) no. 2 TDDDG). You can delete it at any time by clearing this website’s data in your browser’s settings.

5. MCP server for AI agents

Storyframe offers a server based on the Model Context Protocol (MCP) at screenshots.linkandreas.de/mcp, which AI agents such as Claude or Cursor can use to render screenshots. If you connect an AI agent to it, our server processes the requests the agent sends:

  • Content to render: headlines and descriptions, colours, typefaces, layouts, locales and the app screenshots, which the agent sends as image data, as an upload or as a web address (URL).
  • Uploads and results: Uploaded images and the rendered screenshots are kept only in the server’s memory, not written to disk, and deleted after one hour at the latest (earlier if the memory is full). The rendered files can be downloaded by anyone who has their download link; the links contain a random, unguessable code.
  • Images from web addresses: If the agent passes the URL of an image, our server downloads it from that address. The website at that address sees our server’s IP address, not yours.
  • Fonts for other scripts: If a text contains characters that the built-in typefaces do not cover (for example Japanese, Chinese or Arabic), our server requests a matching Noto font from Google Fonts (Google Ireland Limited, Gordon House, Barrow Street, Dublin 4, Ireland). The request contains the characters used in that screen’s text, sorted and without duplicates, and comes from our server, not from your device.
  • Protection against misuse: To limit the number of requests per client, the server counts requests per IP address in its memory for one minute.

The MCP server has no accounts and requires no access keys. We process this data only to render the screenshots you requested (Art. 6(1)(b) GDPR) and to protect the service against misuse (Art. 6(1)(f) GDPR). The AI agent you use and its provider process your data under their own terms and privacy policies, for which they are responsible. Opening the MCP address in a web browser forwards you to the project page on GitHub (GitHub, Inc., USA).

If you run the MCP server on your own computer instead, it renders locally and we receive no data. Only the request for fonts for other scripts described above is then sent from your computer to Google Fonts.
