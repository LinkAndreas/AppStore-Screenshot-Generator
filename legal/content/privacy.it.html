3. Hosting e distribuzione del sito web

Il sito web è ospitato su un server virtuale che noleggiamo da Hostinger (Hostinger International Ltd., 61 Lordou Vironos Street, 6023 Larnaca, Cipro); il server si trova a Francoforte, in Germania. Viene distribuito tramite la rete di Cloudflare (Cloudflare, Inc., 101 Townsend St., San Francisco, CA 94107, USA): ogni richiesta a screenshots.linkandreas.de passa attraverso Cloudflare, che fornisce la connessione HTTPS cifrata, inoltra la richiesta al nostro server attraverso un tunnel sicuro e lo protegge da attacchi e sovraccarichi.

Quando apri il sito web, il tuo browser trasmette necessariamente informazioni tecniche, come il tuo indirizzo IP, la data e l’ora della richiesta, la pagina o il file richiesto, la pagina di provenienza e il tipo e la versione del browser. Cloudflare e il nostro server trattano queste informazioni solo per distribuire il sito web e mantenerlo sicuro e stabile (art. 6, par. 1, lett. f GDPR; il nostro legittimo interesse è un sito web sicuro e funzionante). Il server web sul nostro server virtuale non registra log di accesso. Cloudflare tratta i dati di connessione per distribuire e proteggere il sito web e può anche chiedere al tuo browser di segnalargli le connessioni non riuscite (Network Error Logging).

Per il dominio linkandreas.de è attivo l’offuscamento degli indirizzi email di Cloudflare (Email Obfuscation): per proteggere gli indirizzi email dai bot di spam, Cloudflare riscrive i link email delle nostre pagine al momento della distribuzione e un piccolo script di Cloudflare, caricato dallo stesso indirizzo della pagina, li decodifica di nuovo nel tuo browser. In questo modo non vengono trattati dati personali oltre ai dati di connessione descritti sopra.

4. L’editor nel tuo browser

L’editor elabora tutto localmente nel tuo browser:

  • Screenshot: le immagini che aggiungi vengono aperte direttamente nel tuo browser e non vengono caricate. Restano solo nella memoria del browser e scompaiono quando ricarichi o chiudi la pagina.
  • Il tuo progetto: titoli e descrizioni, stili, layout, le lingue e i dispositivi su cui lavori, il tema chiaro o scuro e l’informazione se hai già visto il tutorial e le ultime “Novità” vengono salvati nella memoria locale del browser (localStorage), così il tuo lavoro è ancora lì la prossima volta che apri Storyframe.
  • Esportazione: gli screenshot finiti e il file ZIP vengono creati nel tuo browser e salvati direttamente sul tuo dispositivo.
  • Lingua: l’editor legge l’impostazione della lingua del browser per mostrare l’interfaccia nella tua lingua; questa informazione non viene salvata né trasmessa.

Nulla di tutto ciò viene trasmesso a noi o a terzi, e non vi abbiamo accesso. Il salvataggio del progetto nella memoria locale è strettamente necessario per fornire l’editor che usi (§ 25, comma 2, n. 2 TDDDG). Puoi eliminarlo in qualsiasi momento cancellando i dati di questo sito web nelle impostazioni del browser.

5. Server MCP per agenti di IA

Storyframe offre su screenshots.linkandreas.de/mcp un server basato sul Model Context Protocol (MCP), che agenti di IA come Claude o Cursor possono usare per generare screenshot. Se colleghi un agente di IA, il nostro server tratta le richieste inviate dall’agente:

  • Contenuti da generare: titoli e descrizioni, colori, caratteri tipografici, layout, lingue (locale) e gli screenshot dell’app, che l’agente invia come dati immagine, come caricamento o come indirizzo web (URL).
  • Caricamenti e risultati: le immagini caricate e gli screenshot generati restano solo nella memoria del server, non vengono scritti su disco e vengono eliminati al più tardi dopo un’ora (prima se la memoria è piena). I file generati possono essere scaricati da chiunque disponga del relativo link di download; i link contengono un codice casuale impossibile da indovinare.
  • Immagini da indirizzi web: se l’agente passa l’URL di un’immagine, il nostro server la scarica da quell’indirizzo. Il sito web a quell’indirizzo vede l’indirizzo IP del nostro server, non il tuo.
  • Font per altri sistemi di scrittura: se un testo contiene caratteri non coperti dai caratteri tipografici integrati (ad esempio giapponese, cinese o arabo), il nostro server richiede un font Noto adatto a Google Fonts (Google Ireland Limited, Gordon House, Barrow Street, Dublin 4, Irlanda). La richiesta contiene i caratteri usati nel testo di quella schermata, ordinati e senza duplicati, e proviene dal nostro server, non dal tuo dispositivo.
  • Protezione dagli abusi: per limitare il numero di richieste per client, il server conta nella sua memoria, per un minuto, le richieste per indirizzo IP.

Il server MCP non ha account e non richiede chiavi di accesso. Trattiamo questi dati solo per generare gli screenshot che hai richiesto (art. 6, par. 1, lett. b GDPR) e per proteggere il servizio dagli abusi (art. 6, par. 1, lett. f GDPR). L’agente di IA che usi e il suo fornitore trattano i tuoi dati secondo i propri termini e le proprie informative sulla privacy, di cui sono responsabili. Se apri l’indirizzo MCP in un browser web, vieni reindirizzato alla pagina del progetto su GitHub (GitHub, Inc., USA).

Se invece esegui il server MCP sul tuo computer, gli screenshot vengono generati in locale e non riceviamo alcun dato. In tal caso, solo la richiesta di font per altri sistemi di scrittura descritta sopra viene inviata dal tuo computer a Google Fonts.
