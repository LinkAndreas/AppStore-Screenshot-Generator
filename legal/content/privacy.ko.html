3. 웹사이트 호스팅 및 전송

이 웹사이트는 Hostinger(Hostinger International Ltd., 61 Lordou Vironos Street, 6023 Larnaca, 키프로스)에서 빌린 가상 서버에서 실행되며, 서버는 독일 프랑크푸르트에 있어요. 웹사이트는 Cloudflare(Cloudflare, Inc., 101 Townsend St., San Francisco, CA 94107, 미국)의 네트워크를 통해 전송돼요. screenshots.linkandreas.de로 가는 모든 요청은 Cloudflare를 거치며, Cloudflare는 암호화된 HTTPS 연결을 제공하고, 보안 터널을 통해 요청을 저희 서버로 전달하며, 서버를 공격과 과부하로부터 보호해요.

웹사이트를 열면 브라우저는 IP 주소, 요청 날짜와 시간, 요청한 페이지나 파일, 참조 페이지, 브라우저 종류와 버전 같은 기술 정보를 필연적으로 전송해요. Cloudflare와 저희 서버는 이 정보를 웹사이트를 전송하고 안전하고 안정적으로 유지하기 위해서만 처리해요 (GDPR 제6조 제1항 (f). 저희의 정당한 이익은 안전하고 제대로 작동하는 웹사이트예요). 가상 서버의 웹 서버는 접속 로그를 기록하지 않아요. Cloudflare는 저희를 대신해 연결 데이터를 처리하며, 연결에 실패하면 이를 Cloudflare에 보고하도록 브라우저에 요청할 수도 있어요(Network Error Logging).

linkandreas.de 도메인에는 Cloudflare의 이메일 난독화(Email Obfuscation)가 활성화되어 있어요. 스팸 봇으로부터 이메일 주소를 보호하기 위해 Cloudflare는 페이지를 전송할 때 페이지의 이메일 링크를 바꿔 쓰고, 페이지와 같은 주소에서 제공되는 Cloudflare의 작은 스크립트가 브라우저에서 이를 다시 원래대로 복원해요. 이 과정에서 위에서 설명한 연결 데이터 외의 개인 데이터는 처리되지 않아요.

4. 브라우저 속 편집기

편집기는 모든 것을 브라우저 안에서 로컬로 처리해요.

  • 스크린샷: 추가한 이미지는 브라우저에서 바로 열리며 업로드되지 않아요. 이미지는 브라우저 메모리에만 보관되고, 페이지를 새로 고치거나 닫으면 사라져요.
  • 프로젝트: 헤드라인과 설명, 스타일, 레이아웃, 작업 중인 언어와 기기, 라이트 또는 다크 테마 설정, 그리고 튜토리얼과 최신 “새로운 기능”을 봤는지 여부는 브라우저의 로컬 저장소(localStorage)에 저장돼요. 그래서 다음에 Storyframe을 열어도 작업 내용이 그대로 남아 있어요.
  • 내보내기: 완성된 스크린샷과 ZIP 파일은 브라우저에서 만들어지고 기기에 바로 저장돼요.
  • 언어: 편집기는 인터페이스를 사용자의 언어로 보여 주기 위해 브라우저의 언어 설정을 읽어요. 이 정보는 저장되거나 전송되지 않아요.

이 중 어떤 것도 저희나 제3자에게 전송되지 않으며, 저희는 이에 접근할 수 없어요. 프로젝트를 로컬 저장소에 저장하는 것은 사용자가 쓰는 편집기를 제공하는 데 반드시 필요해요(독일 전기통신·디지털 서비스 데이터 보호법(TDDDG) 제25조 제2항 제2호). 브라우저 설정에서 이 웹사이트의 데이터를 지우면 언제든지 삭제할 수 있어요.

5. AI 에이전트용 MCP 서버

Storyframe은 screenshots.linkandreas.de/mcp에서 Model Context Protocol(MCP) 기반 서버를 제공하며, Claude나 Cursor 같은 AI 에이전트가 이를 이용해 스크린샷을 렌더링할 수 있어요. AI 에이전트를 연결하면 저희 서버는 에이전트가 보내는 요청을 처리해요.

  • 렌더링할 콘텐츠: 헤드라인과 설명, 색상, 서체, 레이아웃, 로케일, 그리고 앱 스크린샷이에요. 스크린샷은 에이전트가 이미지 데이터나 업로드 파일, 또는 웹 주소(URL)로 보내요.
  • 업로드 및 결과물: 업로드된 이미지와 렌더링된 스크린샷은 서버 메모리에만 보관되고 디스크에 기록되지 않으며, 늦어도 1시간 후에 삭제돼요(메모리가 가득 차면 더 일찍 삭제돼요). 렌더링된 파일은 다운로드 링크를 가진 사람이라면 누구나 다운로드할 수 있어요. 링크에는 추측할 수 없는 무작위 코드가 들어 있어요.
  • 웹 주소의 이미지: 에이전트가 이미지 URL을 전달하면 저희 서버가 그 주소에서 이미지를 다운로드해요. 해당 주소의 웹사이트에는 사용자의 IP 주소가 아니라 저희 서버의 IP 주소가 보여요.
  • 다른 문자 체계용 글꼴: 기본 제공 서체가 지원하지 않는 문자(예: 일본어, 중국어, 아랍어)가 텍스트에 있으면, 저희 서버는 Google Fonts(Google Ireland Limited, Gordon House, Barrow Street, Dublin 4, 아일랜드)에 알맞은 Noto 글꼴을 요청해요. 이 요청에는 해당 화면의 텍스트에 쓰인 문자가 정렬되고 중복이 제거된 형태로 들어 있으며, 요청은 사용자의 기기가 아니라 저희 서버에서 보내요.
  • 오용 방지: 클라이언트별 요청 수를 제한하기 위해 서버는 IP 주소별 요청 수를 1분 동안 메모리에서 집계해요.

MCP 서버에는 계정이 없고 액세스 키도 필요하지 않아요. 저희는 이 데이터를 사용자가 요청한 스크린샷을 렌더링하고(GDPR 제6조 제1항 (b)) 서비스를 오용으로부터 보호하기(GDPR 제6조 제1항 (f)) 위해서만 처리해요. 사용자가 쓰는 AI 에이전트와 그 제공자는 자체 약관과 개인정보 처리방침에 따라 사용자의 데이터를 처리하며, 이에 대한 책임은 그들에게 있어요. 웹 브라우저에서 MCP 주소를 열면 GitHub(GitHub, Inc., 미국)의 프로젝트 페이지로 이동해요.

MCP 서버를 자신의 컴퓨터에서 직접 실행하면 렌더링이 로컬에서 이루어지고 저희는 어떤 데이터도 받지 않아요. 이 경우에는 위에서 설명한 다른 문자 체계용 글꼴 요청만 사용자의 컴퓨터에서 Google Fonts로 전송돼요.

6. 이메일 문의

이메일로 연락하면 저희는 이메일 주소, 메시지 및 그 안에 담긴 정보를 문의에 답변하기 위해서만 처리하며(GDPR 제6조 제1항 (b) 및 (f)), 더 이상 필요하지 않게 되면 삭제해요.

7. 수령자 및 수탁자

저희는 개인 데이터를 판매하거나 대여하거나 공유하지 않아요. 다음 서비스 제공자가 저희를 대신해 저희의 지시에 따라 데이터를 처리해요.

  • Hostinger – 가상 서버 운영(3절).
  • Cloudflare – 웹사이트와 MCP 서버의 전송 및 보호(3절).

Google은 글꼴 제공자로서 5절에서 설명한 MCP 서버의 글꼴 요청을 받아요.

8. 제3국으로의 이전

Cloudflare, Inc.와 Google Ireland Limited의 모회사인 Google LLC는 미국에 있으므로 개인 데이터가 미국에서 처리될 수 있어요. 또한 Cloudflare는 전 세계 네트워크를 운영하므로 연결 데이터가 유럽경제지역(EEA) 밖의 다른 국가에서 처리될 수도 있어요. 두 회사 모두 EU–U.S. Data Privacy Framework(EU-미국 데이터 프라이버시 프레임워크) 인증을 받았으며, 유럽연합 집행위원회는 이 프레임워크에 대해 적정성 결정을 채택했어요(GDPR 제45조).

9. 보관 기간

  • 브라우저 로컬 저장소의 데이터는 사용자가 삭제할 때까지 기기에 남아 있어요.
  • MCP 서버의 업로드 및 렌더링된 파일은 늦어도 1시간 후에, 요청 수 집계는 1분 후에 삭제돼요.
  • 이메일은 법정 보관 기간이 적용되는 경우를 제외하고, 문의 처리가 끝나면 삭제해요.

10. 사용자의 권리

GDPR에 따라 사용자는 열람권(제15조), 정정권(제16조), 삭제권(제17조), 처리 제한권(제18조), 개인정보 이동권(제20조), 그리고 정당한 이익에 근거한 처리에 반대할 권리(제21조)를 가져요. 이 권리를 행사하려면 저희에게 연락만 하면 돼요. 편집기는 데이터를 사용자의 기기에 보관하므로, 언제든지 직접 확인하고 삭제할 수 있어요.

11. 민원을 제기할 권리

사용자는 데이터 보호 감독 기관에 민원을 제기할 권리가 있으며(GDPR 제77조), 특히 상거소지나 근무지가 있는 EU 회원국의 감독 기관에 제기할 수 있어요. 저희를 관할하는 감독 기관은 Landesbeauftragte für den Datenschutz und die Informationsfreiheit Baden-Württemberg(바덴뷔르템베르크주 데이터 보호 및 정보 자유 감독관), Lautenschlagerstraße 20, 70173 Stuttgart, 독일이에요.
