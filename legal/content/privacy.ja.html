3. Web サイトのホスティングと配信

本 Web サイトは、Hostinger（Hostinger International Ltd., 61 Lordou Vironos Street, 6023 Larnaca, キプロス）から借りている仮想サーバー上で稼働しています。サーバーの所在地はドイツ・フランクフルトです。配信には Cloudflare（Cloudflare, Inc., 101 Townsend St., San Francisco, CA 94107, アメリカ合衆国）のネットワークを利用しています。screenshots.linkandreas.de へのすべてのリクエストは Cloudflare を経由します。Cloudflare は暗号化された HTTPS 接続を提供し、安全なトンネルを通じてリクエストを当方のサーバーに転送し、サーバーを攻撃や過負荷から保護します。

本 Web サイトを開くと、お使いのブラウザは必然的に、IP アドレス、リクエストの日時、リクエストされたページまたはファイル、参照元ページ、ブラウザの種類とバージョンなどの技術情報を送信します。Cloudflare と当方のサーバーは、これらの情報を Web サイトの配信と、その安全性および安定性の確保のためにのみ処理します（GDPR 第 6 条第 1 項 (f)。当方の正当な利益は、安全で正常に機能する Web サイトです）。当方の仮想サーバー上の Web サーバーはアクセスログを記録しません。Cloudflare は Web サイトの配信と保護のために接続データを処理し、接続に失敗した場合にそれを Cloudflare に報告するようブラウザに求めることもあります（Network Error Logging）。

linkandreas.de ドメインでは Cloudflare のメールアドレス難読化（Email Obfuscation）が有効になっています。メールアドレスをスパムボットから守るため、Cloudflare はページの配信時にページ内のメールリンクを書き換え、ページと同じアドレスから読み込まれる Cloudflare の小さなスクリプトがブラウザ内でそれを元に戻します。これにより、上記の接続データ以外の個人データが処理されることはありません。

4. ブラウザ内のエディタ

エディタはすべてをお使いのブラウザ内でローカルに処理します。

  • スクリーンショット：追加した画像はブラウザ内で直接開かれ、アップロードされることはありません。画像はブラウザのメモリ内にのみ保持され、ページを再読み込みするか閉じると消去されます。
  • プロジェクト：見出しと説明文、スタイル、レイアウト、作業中の言語とデバイス、ライトテーマまたはダークテーマの設定、およびチュートリアルと最新の「新機能」を表示済みかどうかは、ブラウザのローカルストレージ（localStorage）に保存されます。これにより、次に Storyframe を開いたときにも作業内容がそのまま残ります。
  • 書き出し：完成したスクリーンショットと ZIP ファイルはブラウザ内で作成され、お使いのデバイスに直接保存されます。
  • 言語：エディタは、インターフェイスをお使いの言語で表示するためにブラウザの言語設定を読み取ります。この情報は保存も送信もされません。

これらの情報が当方や第三者に送信されることはなく、当方がアクセスすることもできません。プロジェクトをローカルストレージに保存することは、利用者が使うエディタを提供するために厳密に必要なものです（TDDDG 第 25 条第 2 項第 2 号）。ブラウザの設定でこの Web サイトのデータを消去することで、いつでも削除できます。

5. AI エージェント向け MCP サーバー

Storyframe は、screenshots.linkandreas.de/mcp で Model Context Protocol（MCP）に基づくサーバーを提供しており、Claude や Cursor などの AI エージェントがスクリーンショットの生成に利用できます。AI エージェントを接続すると、当方のサーバーはエージェントが送信するリクエストを処理します。

  • 生成するコンテンツ：見出しと説明文、色、書体、レイアウト、ロケール、およびアプリのスクリーンショット。スクリーンショットはエージェントから画像データ、アップロード、または Web アドレス（URL）として送信されます。
  • アップロードと生成結果：アップロードされた画像と生成されたスクリーンショットはサーバーのメモリ内にのみ保持され、ディスクには書き込まれず、遅くとも 1 時間後に削除されます（メモリがいっぱいになった場合はそれより早く削除されます）。生成されたファイルは、ダウンロードリンクを知っている人であれば誰でもダウンロードできます。リンクには推測できないランダムなコードが含まれています。
  • Web アドレスからの画像：エージェントが画像の URL を渡した場合、当方のサーバーはそのアドレスから画像をダウンロードします。そのアドレスの Web サイトに見えるのは当方のサーバーの IP アドレスであり、利用者の IP アドレスではありません。
  • ほかの文字体系用のフォント：内蔵の書体でカバーされていない文字（日本語、中国語、アラビア語など）がテキストに含まれる場合、当方のサーバーは Google Fonts（Google Ireland Limited, Gordon House, Barrow Street, Dublin 4, アイルランド）に適切な Noto フォントをリクエストします。このリクエストには、その画面のテキストで使用されている文字が、並べ替えられ重複を除いた形で含まれます。リクエストはお使いのデバイスからではなく、当方のサーバーから送信されます。
  • 不正利用の防止：クライアントごとのリクエスト数を制限するため、サーバーは IP アドレスごとのリクエスト数を 1 分間メモリ内で集計します。

MCP サーバーにはアカウントがなく、アクセスキーも必要ありません。当方はこれらのデータを、利用者が依頼したスクリーンショットを生成するため（GDPR 第 6 条第 1 項 (b)）、およびサービスを不正利用から保護するため（GDPR 第 6 条第 1 項 (f)）にのみ処理します。利用者が使う AI エージェントとその提供者は、それぞれ独自の規約とプライバシーポリシーに基づいて利用者のデータを処理し、その責任を負います。MCP のアドレスを Web ブラウザで開くと、GitHub（GitHub, Inc., アメリカ合衆国）のプロジェクトページに転送されます。

MCP サーバーを自分のコンピュータで実行する場合は、スクリーンショットがローカルで生成され、当方はデータを一切受け取りません。その場合、上記のほかの文字体系用フォントのリクエストのみが、お使いのコンピュータから Google Fonts に送信されます。
